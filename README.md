# 素材管理器（主程序）

本地优先的素材管理桌面工具（纯净框架版）。**主程序零类型知识**：文件是否算素材，
完全由插件注册表判定（扩展名 → 插件 的映射来自插件声明）。插件的类别、缩略图、
预览、右键操作、详情栏、设置项全部来自插件自身声明。

- **无插件形态**：主程序正常运行，但不显示任何文件（界面只有目录结构与基础管理）
- **安装插件后**：对应类型的素材自动进入索引并可浏览
- 插件安装方式：设置页 →「安装插件」→ 选择 **`.zip` 压缩包**（内含 `index.cjs`）
- 自带插件：`plugins/blender工程/`（Blender 工程，声明 `.blend`）、
  `plugins/mmd模型/`（MMD 模型，声明 `.pmx`/`.pmd`，独立窗口 3D 实时预览 + 生成缩略图）、
  `plugins/视频/`（视频，声明 `.mp4`/`.webm`/`.mov`，独立窗口播放器 + 从视频抽帧生成缩略图）

## 快速开始

```bash
npm install        # 安装 electron
npm start          # 启动应用
```

双击 `start-app.cmd` 也可启动。

## 功能

- **素材库管理**：添加 / 移除根目录（多根、可启停）、增量扫描（目录指纹，秒级）
- **浏览**：左侧目录树、网格 / 列表视图、排序（名称 / 时间 / 体积）、右键菜单；
  **在空白处双击可返回上一级目录**（已在素材库根目录时不动作，不会跳出素材库）
- **目录树定位**：点素材 / 进文件夹时，左侧树自动定位并高亮到对应目录，
  且**只展开当前位置这一条链**，其它分支自动收起 ——
  连续浏览不同分支时树不会被撑开一大片，当前所在位置始终清晰
- **详情栏常驻**：右侧详情栏**始终占位**（未选中时显示占位提示），
  宽度可拖拽调整并记忆。选中 / 取消素材只切换内容、不改变宽度 ——
  左侧素材区不会因详情栏开关而重排、卡片不会跳位
- **排序记忆**：排序方案**每个文件夹各记各的**并持久化到 `settings.json`。
  进目录时自动套用该目录上次的选择，没记录过的目录回落全局默认（按名称升序）；
  目录被删除/改名后，对应记录会在下次扫描时自动清理，不会越积越多
- **检索**：名称 / 路径 / 标签 / 备注 全文
- **标签 / 收藏 / 备注**：单个与批量操作
- **清理**：清除缩略图时只把**名字里带 `.preview.`** 的缩略图移入系统回收站（可还原），其它图片一律不碰；插件卸载则是删除整个插件目录（不可还原）
- **素材文件只读**：主程序**刻意不提供任何删除/修改素材文件的通道**，素材只能由用户在文件管理器中处理
- **主文件消失**：扫描时直接从索引移除（不再标记「丢失」）
- **缩略图（显示）**：只取素材同目录、**名为「素材文件名 + `.preview.` + 图片扩展名」**的图片（`a.blend` → `a.blend.preview.png`）；没有则只显示文件类型占位。
  名字里既保留素材扩展名（让 `a.blend` 与 `a.pmx` 各自独立、不共用一张图），又带 `.preview.` 标记（一眼看出哪些文件是缩略图，也避免误认用户自己的图片）
- **缩略图（生成）**：顶栏「缩略图」按钮 → 对当前范围内「插件声明 canThumbnail」的素材离屏渲染，产物按上述命名写到素材同目录；已有缩略图的素材一律跳过，绝不覆盖
- **实时预览**：插件 canPreview → 独立预览窗口（样式来自插件 previewHtml）。
  窗口级框架能力由主程序提供：**Esc 关闭窗口**、**左上角信息条**（素材名 +
  「生成预览图」按钮）。按钮调插件 `snapshot()` 拿当前画面，按 `<素材名>.preview.png`
  存盘（已有则替换，用户自己的同名图片不碰），**存完主界面立刻刷新那一张图**，无需重扫。
  插件没实现 `snapshot()` 时按钮显示为**置灰不可点**并说明原因
- **双击行为**：插件用 `dblclick` 声明双击素材做什么（`preview` / `open` / `none`），
  **不声明则不做任何操作**；设置页可按插件覆盖
- **详情栏**：插件 detail 字段 + parse 元数据 + 通用键值；插件可用 `detail.buttons` 放自己的按钮（返回值以长文本弹窗呈现）；切换目录/素材库/搜索时自动关闭
- **设置**：扫描并发、缩略图尺寸（128/256/512/1024/2048 五档）、素材库管理、**插件管理**（安装 zip / 卸载 / 启停 / 插件自定义设置）
- **即时生效**：收藏/标签/备注、素材库启停、插件安装/卸载/启停/设置保存、**手动放置或生成缩略图后重新扫描**，均在当前界面立即更新
- **干净退出**：关闭主窗口即退出整个软件，预览窗口与全部子进程一并回收，不留残余

## 无插件行为（架构红线）

- 扫描时逐文件查询插件注册表；**无插件声明该扩展名 → 该文件不是素材，不索引、不显示**
- 无插件状态下：扫描不产生任何素材条目，界面只显示目录结构与空状态提示
- 卸载/禁用插件：该类型全部条目从索引移除（不再是素材）

  asset.test.js         asset:// 路径归属校验
  icon.test.js          插件图标流程
  pluginguard.test.js   插件调用兜底（超时 / 异常隔离 / 返回值保留）

  video-thumb.test.js   视频抽帧生成缩略图（由主程序拉起，走真实离屏管线）

## 数据存储

数据位于**软件主目录下的 `data/`**（便携，随程序走；可用环境变量 `AMM_DATA_DIR` 覆盖）：

- `settings.json`：全局设置、素材库列表、禁用插件列表、**每个文件夹的排序方案**
  （`folderSort` 字段，键为 `<素材库id>\0<相对路径>`；用相对路径是为了换盘符/换机器后仍然有效）
- `index/index-<rootId>.json`：每根目录索引分片（条目 + 目录指纹 + 插件签名）
- `plugin-settings.json`：插件自定义设置
- `plugin-overrides.json`：插件在界面上的改动（显示名/类别色/图标等），不写回插件文件

> 早期版本的数据位于系统 userData 目录，启动时会自动迁移到上述位置（旧目录保留作备份）。

### 插件调用的兜底

插件在主进程里以完整 Node 权限运行，所以「插件出错不能拖垮软件」是硬要求。
`src/main/pluginGuard.js` 统一给每次插件调用加超时与异常隔离：

- `parse` 抛异常或卡住 → 只影响该素材（降级无元数据），扫描继续
- 插件 `action` 抛异常或卡住 → 返回可读错误给用户，界面不失去响应
- 超时默认：parse 30s / action 60s，可用 `AMM_PLUGIN_TIMEOUT_PARSE` 等环境变量覆盖

注意超时是「**调用方放弃等待**」：同进程内无法杀死一段同步死循环的代码。
对异步挂起完全有效；彻底隔离需要 `utilityProcess`，未做。

### 安装第三方插件的风险

插件能读写任意文件、联网、起子进程 —— **装一个 zip 等于信任它的作者**。
因此安装前会弹出明确的风险提示，由用户确认后才解压。

## 打包便携版

```powershell
powershell -ExecutionPolicy Bypass -File build-portable.ps1
```

产出 `dist\素材管理器-便携版\`（约 231 MB），双击 `素材管理器.exe` 即用。

要点：

- 程序**零运行时依赖**，只需 Electron 运行时 + 源码
- 语言包裁剪到中英文（40 MB → 1.9 MB）
- `plugins/` 与 `data/` 放在 `resources/app/` 下，**与源码目录结构一致** ——
  这样主程序里 `__dirname/../../plugins` 的定位逻辑不用改一行代码
- 便携性：配置和数据都在程序内，整个文件夹拷走即带走全部设置，卸载 = 删文件夹

## 关于素材

本程序**不提供任何素材**。它管理的模型、动作、音频、视频等全部来自你本机 ——
比如动作插件需要套用的 MMD 模型，由你在插件设置里指定自己的模型文件夹。

各插件只含渲染/解析代码，不含素材数据。素材的授权请遵循其原作者条款，
与本项目的 MIT 许可无关。
